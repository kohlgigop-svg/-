方法说明

本页说明工具内部使用的全部计算口径，便于审计与复核。所有公式均经单元测试验证。

1. 方向约定

正例 = 驳回（坏数据），负例 = 通过（好数据）。所有指标以此为前提，换方向会使召回率与精确率的含义互换。

2. 指标定义

指标公式分母管什么
准确率 Acc(TP+TN)/N抽样总数整体协调性，π 偏离均衡时被稀释，不作主指标
精确率 PTP/(TP+FP)质检驳回数驳得准不准（受 π 稀释）
召回率 RTP/(TP+FN)实际应驳回数漏没漏（关联不可逆风险）
特异度 SpecTN/(TN+FP)实际合格数冤没冤（衡量误判只能用这个）
Fβ(1+β²)·P·R / (β²·P + R)—P、R 的加权调和平均，权重比 = β²

β 的权重关系：β=2 表示召回率权重是精确率的 4 倍（β²），不是 2 倍。β=1 退化为 F1。

3. 置信区间

  • 比例型指标（Acc / P / R / Spec / NPV）用 Wilson 区间，不用 Wald。Wald 在 n=100、k=0 时给出 [0, 0]，等于宣称漏判率精确为 0；Wilson 给出 [0, 3.7%]，才反映真实不确定性。
  • F 族指标用参数 Bootstrap（默认 B=4000）。F1 是 P 与 R 的非线性组合且二者由同一个 TP 决定（负相关），分别求区间再代入会丢掉相关性。
  • 随机数使用固定种子，同一份数据每次得到完全一致的区间，保证可复核。
  • n 是各指标自己的分母，不是抽样总量。同一个抽样集合里，P 与 R 的 n 可能相差一个数量级。

4. 警戒线（只对召回率设置）

  1. 基线 B = 前三次评估的实际驳回率中的最高值（不足三次则取全部；无历史则取本次）
  2. 容忍率 T = 1 − 需求方要求的验收准确率
  3. 召回率下限 R_min = 1 − T/B；若 R_min ≤ 0（即 B ≤ T），退化为历史最差召回率
  4. 可容忍漏判条数 = max(1, 实际应驳回数 × (1 − R_min))

判定用区间下限：区间下限 ≥ R_min 判为达标；区间跨越 R_min 判为不确定（不作结论）；区间上限低于 R_min 判为确证问题。 只对召回率设绝对警戒线，因为漏判通常不可逆；精确率属返修成本，只在效率维度作相对比较。

5. 观察线

  • 各指标取前 k 次统计的中位数（k 默认 3，可在输入区调整）
  • 不足 k 次时取现有全部值的中位数，并标注稳健性有限
  • 连续两次低于观察线才提示纳入观察，单次低于不作结论

6. 三态判定（信号与噪声）

区间位置判定动作
下限已高于警戒线未见实质问题不动作，不进入复盘
跨越警戒线不确定增大样本量后再判，本次不作结论
上限已低于警戒线确证问题进入复盘，做错误归因

7. 分层抽样

  • 点估计仍用抽样内的真实计数：P、R、F1 等为比值，加权前后取值相同
  • 有效样本量（经典口径）n_eff = (Σw)² / Σw²，w = 1/入样概率；同时给出计入有限总体校正 (1−f) 的口径
  • 过采样「已驳回层」可提高该层精度，但总体层面的有效信息量会被折算，报告时应同时给出有效样本量

8. 本工具的边界

  • 指标体系回答「哪里可能有问题」，不回答「这个人行不行」
  • 样本量不足（区间过宽）时禁止作任何评价；工具会在诊断卡中明确提示
  • 不适用多分类质检（通过/驳回/返修），需扩展为宏平均或微平均
  • 指标与个人奖惩直接挂钩会诱发指标操纵（压低驳回量即可让 P 好看），且把风险转移给下游
